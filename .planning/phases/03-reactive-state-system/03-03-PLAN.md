  <name>Task 1: Add SubscriberSet with TypeId dispatch and global event bus</name>
  <files>ora/src/subscription.rs</files>
  <action>
Extend `ora/src/subscription.rs` with:

1. `SubscriberCallback` type: `Box<dyn FnMut(&dyn Any, &mut AppContext)>` -- receives type-erased event and mutable AppContext. The callback internally downcasts to the concrete event type.

2. `SubscriberSet` struct:
   - `subscribers: HashMap<EntityId, HashMap<TypeId, Vec<(SubscriptionId, SubscriberCallback)>>>` -- per-entity, per-event-type subscriber lists
   - `next_id: SubscriptionId` (or share the same counter as ObserverSet -- unify into a single `next_subscription_id` in a shared location)

3. `SubscriberSet` methods:
   - `pub fn new() -> Self`
   - `pub fn subscribe<E: 'static>(&mut self, emitter: EntityId, callback: SubscriberCallback) -> SubscriptionId` -- registers callback for (emitter, TypeId::of::<E>())
   - `pub fn remove_subscription(&mut self, emitter: EntityId, event_type: TypeId, id: SubscriptionId)` -- removes specific subscription
   - `pub fn remove_all_for_entity(&mut self, entity_id: EntityId)` -- removes all subscriptions where entity_id is the emitter (for entity cleanup on removal)
   - `pub fn take_subscribers_for(&mut self, emitter: EntityId, event_type: TypeId) -> Vec<(SubscriptionId, SubscriberCallback)>` -- take for safe invocation
   - `pub fn restore_subscribers(&mut self, emitter: EntityId, event_type: TypeId, callbacks: Vec<(SubscriptionId, SubscriberCallback)>)` -- put back after invocation

4. `GlobalEventBus` struct:
   - `subscribers: HashMap<TypeId, Vec<(SubscriptionId, Box<dyn FnMut(&dyn Any, &mut AppContext)>)>>` -- no entity_id, just event type
   - `next_id: SubscriptionId`

5. `GlobalEventBus` methods:
   - `pub fn new() -> Self`
   - `pub fn subscribe<E: 'static>(&mut self, callback: Box<dyn FnMut(&dyn Any, &mut AppContext)>) -> SubscriptionId`
   - `pub fn remove_subscription(&mut self, event_type: TypeId, id: SubscriptionId)`
   - `pub fn take_subscribers_for(&mut self, event_type: TypeId) -> Vec<(SubscriptionId, Box<dyn FnMut(&dyn Any, &mut AppContext)>)>`
   - `pub fn restore_subscribers(&mut self, event_type: TypeId, callbacks: Vec<(SubscriptionId, Box<dyn FnMut(&dyn Any, &mut AppContext)>)>)`

6. Update `Subscription` to support full Drop cleanup:
   - Add a thread-local `PENDING_CLEANUPS: RefCell<Vec<CleanupAction>>` where `CleanupAction` is an enum:
     - `RemoveObserver { observed: EntityId, id: SubscriptionId }`
     - `RemoveSubscriber { emitter: EntityId, event_type: TypeId, id: SubscriptionId }`
     - `RemoveGlobalSubscriber { event_type: TypeId, id: SubscriptionId }`
   - `Subscription::drop()` pushes a CleanupAction to PENDING_CLEANUPS
   - `pub fn drain_pending_cleanups() -> Vec<CleanupAction>` -- called by AppContext at start of flush_effects

   This decouples Subscription Drop from AppContext access, making Drop safe to call from any context.

**ora/src/context.rs** -- Update AppContext:

1. Add fields:
   - `pub(crate) subscriber_set: SubscriberSet`
   - `pub(crate) global_event_bus: GlobalEventBus`
   Initialize both in `new()`.

2. Add method `pub fn subscribe<E: 'static>(&mut self, model: &Model<impl 'static>, callback: impl FnMut(&E, &mut AppContext) + 'static) -> Subscription`:
   - Get emitter entity_id from model
   - Wrap callback: create a `Box<dyn FnMut(&dyn Any, &mut AppContext)>` that downcasts `&dyn Any` to `&E` and calls the original callback
   - Register in subscriber_set.subscribe::<E>(entity_id, wrapped)
   - Return Subscription with CleanupAction::RemoveSubscriber info

3. Add method `pub fn subscribe_global<E: 'static>(&mut self, callback: impl FnMut(&E, &mut AppContext) + 'static) -> Subscription`:
   - Same wrapping pattern but registers in global_event_bus
   - Return Subscription with CleanupAction::RemoveGlobalSubscriber info

4. Add method `pub fn emit_global<E: 'static>(&mut self, event: E)`:
   - Directly dispatches to global_event_bus subscribers (global events are immediate, not queued through EffectQueue -- they're app-level broadcasts like theme changes)
   - OR: queue as a special global effect. Decision: queue in effect_queue as Emit with a sentinel "global" EntityId (e.g., EntityId with generation 0, index usize::MAX). Simpler to reuse existing emit infrastructure.
   - Actually, simplest approach: push to emit_queue with a special GLOBAL_ENTITY_ID constant. In flush, if emitter == GLOBAL_ENTITY_ID, dispatch to global_event_bus instead of subscriber_set.

5. Update `flush_effects()`:
   - At start: drain pending cleanups from thread-local and apply them to observer_set, subscriber_set, global_event_bus
   - After processing notify queue (existing), process emit queue:
     ```
     let emitted = self.effect_queue.drain_emit();
     for (emitter, event_type_id, event) in emitted {
         if emitter == GLOBAL_ENTITY_ID {
             // Dispatch to global event bus
             let mut callbacks = self.global_event_bus.take_subscribers_for(event_type_id);
             for (_id, callback) in callbacks.iter_mut() {
                 callback(&*event, self);
             }
             self.global_event_bus.restore_subscribers(event_type_id, callbacks);
         } else {
             // Dispatch to per-entity subscribers
             let mut callbacks = self.subscriber_set.take_subscribers_for(emitter, event_type_id);
             for (_id, callback) in callbacks.iter_mut() {
                 callback(&*event, self);
             }
             self.subscriber_set.restore_subscribers(emitter, event_type_id, callbacks);
         }
     }
     ```

6. Update entity removal: when removing a model, also call `subscriber_set.remove_all_for_entity()` and `observer_set` cleanup for that entity.
