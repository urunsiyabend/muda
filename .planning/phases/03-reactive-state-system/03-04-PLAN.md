1. OraApp struct now stores `app_context: AppContext` (from Plan 02 refactor). Verify this is in place.

2. In `window_event()` after processing any event:
   - Tick the async executor: `while self.app_context.tick_executor() {}`
   - Check for dirty entities and request redraw if dirty

3. In `window_event()` for `RedrawRequested`:
   - Current: renders every frame unconditionally with continuous `request_redraw()`
   - Change to: render only when dirty OR when the frame was explicitly requested
   - After rendering, clear dirty_entities
   - DO NOT call `request_redraw()` automatically after every render. Instead, only call it if:
     a. There are dirty entities remaining (cascading effects)
     b. The executor has pending tasks (async work may produce updates)
     c. Animations are active (Phase 9, not yet)
   - For now, KEEP continuous redraw (request_redraw after every render) to maintain current demo behavior. The optimization to skip rendering when not dirty can be added as a refinement but should not break existing behavior. Add a TODO comment noting the optimization opportunity.

4. Add `about_to_wait` handler:
   ```rust
   fn about_to_wait(&mut self, _event_loop: &ActiveEventLoop) {
       // Tick async executor when event queue is empty
       while self.app_context.tick_executor() {}

       // If executor produced dirty entities, request redraw
       if self.app_context.has_dirty_entities() {
           if let Some(gpu_state) = &self.gpu_state {
               gpu_state.window.request_redraw();
           }
       }
   }
   ```

4. `on_open` callback:
   ```rust
   App::new()
       .title("Reactive Demo")
       .size(400, 300)
       .on_open(|cx| {
           let model = cx.new_model(CounterState { count: 0 });
           let view = CounterView { model: model.clone() };

           // Set up observation
           cx.observe(&model, |cx| {

       })
       .run();
   ```
