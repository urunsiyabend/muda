  <action>
Create `ora/src/effect.rs` with:

1. `EntityId` type alias: `pub type EntityId = generational_arena::Index;`

2. `Effect` enum with two variants (Spawn added in Plan 04):
   - `Notify { emitter: EntityId }` -- marks an entity as dirty
   - `Emit { emitter: EntityId, event_type_id: std::any::TypeId, event: Box<dyn std::any::Any> }` -- carries typed event payload

3. `EffectQueue` struct with:
   - `notify_queue: VecDeque<EntityId>` -- high priority (Notify effects, deduplicated)
   - `notify_set: HashSet<EntityId>` -- O(1) dedup check for notify
   - `emit_queue: VecDeque<(EntityId, TypeId, Box<dyn Any>)>` -- mid priority (Emit effects)
   - `depth: usize` -- current flush depth for cascade detection

4. `EffectQueue` methods:
   - `pub fn new() -> Self`
   - `pub fn push_notify(&mut self, emitter: EntityId)` -- deduplicate using notify_set, only push if not already present
   - `pub fn push_emit(&mut self, emitter: EntityId, event_type_id: TypeId, event: Box<dyn Any>)` -- always push (no dedup for emit)
   - `pub fn is_empty(&self) -> bool` -- both queues empty
   - `pub fn drain_notify(&mut self) -> Vec<EntityId>` -- drain notify_queue AND clear notify_set, return all entity IDs
   - `pub fn drain_emit(&mut self) -> Vec<(EntityId, TypeId, Box<dyn Any>)>` -- drain emit_queue
   - `pub fn depth(&self) -> usize` -- read current depth
   - `pub fn inc_depth(&mut self)` -- increment depth counter
   - `pub fn dec_depth(&mut self)` -- decrement depth counter

Note: The flush logic (which calls observers/subscribers) lives in AppContext (Plan 02). EffectQueue is just a data structure here.

Use `std::collections::{VecDeque, HashSet}` and `std::any::{Any, TypeId}`.

     1. self.update_depth += 1
     2. Create ModelContext with model.entity_id()
     3. Get &mut T from entity_storage.update()
     4. Call f(&mut data, &mut model_cx)
     5. Drain model_cx pending effects into self.effect_queue
     6. self.update_depth -= 1
     7. If self.update_depth == 0, call self.flush_effects() (stub -- just log for now, real implementation in Plan 02)
     8. Return result
   - Add method: `fn flush_effects(&mut self)` -- STUB: log::trace!("flush_effects: {} notify, {} emit pending", ...) and clear queues. Real implementation in Plan 02.

   IMPORTANT BORROW CHECKER NOTE: `update_model` needs `&mut self` for entity_storage AND to drain effects after. The closure receives `(&mut T, &mut ModelContext)` -- ModelContext does NOT hold a reference to AppContext (it has its own pending buffer). After the closure returns, we drain from ModelContext into effect_queue. This avoids aliased mutable borrows.

   The tricky part: `entity_storage.update(entity, |data| f(data, &mut model_cx))`. The entity_storage.update takes FnOnce(&mut T) -> R, but we need to also pass ModelContext. Solution: create model_cx BEFORE calling entity_storage.update, then inside the closure capture it:
   ```rust
   let entity_id = model.entity_id();
   self.update_depth += 1;
   let mut model_cx = ModelContext::new(entity_id);
   let result = self.entity_storage.update(&model.entity, |data| {
       f(data, &mut model_cx)
   });
   // Drain effects
   for (eid, effect) in model_cx.drain() { ... }
   self.update_depth -= 1;
   if self.update_depth == 0 { self.flush_effects(); }
   result
   ```
