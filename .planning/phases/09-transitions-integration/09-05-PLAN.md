  1. Define `CoreEditorAdapter` struct wrapping `core_editor::app::App`:
     ```rust
     pub struct CoreEditorAdapter {
         pub app: core_editor::app::App,
     }
     ```

  2. Implement `From` conversions for each type pair (core_editor -> ora mirror type):
     - `From<core_editor::view_model::TextStyle> for ora::editor_adapter::TextStyle`
     - `From<core_editor::view_model::VisualPosition> for ora::editor_adapter::VisualPosition`
     - `From<core_editor::view_model::StyledSpan> for ora::editor_adapter::StyledSpan`
     - `From<core_editor::view_model::LinePresentation> for ora::editor_adapter::LinePresentation`
     - `From<core_editor::view_model::GutterModel> for ora::editor_adapter::GutterModel`
     - `From<core_editor::view_model::StatusPresentation> for ora::editor_adapter::StatusPresentation`
     - `From<core_editor::view_model::CaretPresentation> for ora::editor_adapter::CaretPresentation`
     - `From<core_editor::view_model::DialogPresentation> for ora::editor_adapter::DialogPresentation`
     - `From<core_editor::view_model::TabPresentation> for ora::editor_adapter::TabPresentation`
     - `From<core_editor::view_model::TabBarPresentation> for ora::editor_adapter::TabBarPresentation`
     - `From<core_editor::view_model::FileTreeNode> for ora::editor_adapter::FileTreeNode`
     - `From<core_editor::view_model::FileTreePresentation> for ora::editor_adapter::FileTreePresentation`
     - `From<core_editor::view_model::SidebarPresentation> for ora::editor_adapter::SidebarPresentation`
     - `From<core_editor::view_model::RenderModel> for ora::editor_adapter::RenderModel`

     Each From impl maps fields 1:1 (same names). For nested types (e.g., RenderModel.visible_lines is Vec<LinePresentation>), map with `.into_iter().map(Into::into).collect()`.

  3. Implement `ora::editor_adapter::EditorDataSource for CoreEditorAdapter`:
     - `build_render_model(&self, viewport_lines: usize) -> ora::editor_adapter::RenderModel`:
       Call `self.app.build_render_model(viewport_lines)` and `.into()` the result.
       Read `core_editor/src/view_model/builder.rs` to verify the exact method signature — it may be `ViewModelBuilder::build()` rather than `app.build_render_model()`. Adapt accordingly.
     - `dispatch_command(&mut self, cmd: EditorCommand)`:
       Match on EditorCommand variants and call corresponding methods on `self.app`. Reference `wgpu_client/src/input.rs` for the mapping of key events to editor actions.
     - `window_title(&self) -> String`:
       Return the document title from the app.

  4. Add `mod adapter;` to `wgpu_client/src/main.rs`.

     - Ctrl+A -> SelectAll
     - Ctrl+C/X/V -> Copy/Cut/Paste
     - Tab -> InsertTab
     - Home/End/PageUp/PageDown -> corresponding movement
