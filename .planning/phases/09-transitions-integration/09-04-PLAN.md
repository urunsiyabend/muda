  <name>Task 1: Create TransitionSpec, TransitionState, and TransitionRegistry types</name>
  <files>ora/src/animation/transition.rs, ora/src/animation/mod.rs</files>
  <action>
  Create `ora/src/animation/transition.rs` with these types:

  ```rust
  use std::collections::HashMap;
  use std::time::Instant;
  use super::easing::Easing;
  use super::tween::{Tween, TweenState};
  use crate::style::Color;

  /// Stable identity for transition state across frames.
  /// Assigned explicitly by callers via .transition_id() builder method.
  /// Elements are ephemeral (recreated each frame), but TransitionId persists.
  #[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
  pub struct TransitionId(pub u64);

  /// Configuration for a single property transition.
  #[derive(Clone, Copy, Debug)]
  pub struct TransitionConfig {
      pub duration_ms: u32,
      pub easing: Easing,
  }

  /// Declares which properties can transition and how.
  /// Stored on Div struct, checked during paint.
  #[derive(Clone, Debug, Default)]
  pub struct TransitionSpec {
      pub bg: Option<TransitionConfig>,
      pub opacity: Option<TransitionConfig>,
      pub color: Option<TransitionConfig>,       // text/border color
      pub position: Option<TransitionConfig>,     // paint-time transform offset
  }

  /// Live transition state for one element, stored in TransitionRegistry.
  pub struct TransitionState {
      pub bg_tween: Option<Tween<Color>>,
      pub opacity_tween: Option<Tween<f32>>,
      pub color_tween: Option<Tween<Color>>,
      pub position_x_tween: Option<Tween<f32>>,
      pub position_y_tween: Option<Tween<f32>>,
      last_bg_target: Option<Color>,
      last_opacity_target: Option<f32>,
      last_color_target: Option<Color>,
  }
  ```

  Implement methods on `TransitionState`:
  - `new() -> Self` (all fields None)
  - `advance_bg(&mut self, target: Color, config: &TransitionConfig) -> Color`:
    If target differs from `last_bg_target`, retarget the tween (or create new one from current value). Call tween.update(). Return tween.value_owned(). Update `last_bg_target`.
  - `advance_opacity(&mut self, target: f32, config: &TransitionConfig) -> f32`: Same pattern.
  - `advance_color(&mut self, target: Color, config: &TransitionConfig) -> Color`: Same pattern.
  - `is_active(&self) -> bool`: Returns true if any tween is in Playing state.

  Define `TransitionRegistry`:
  ```rust
  pub struct TransitionRegistry {
      states: HashMap<TransitionId, TransitionState>,
  }

  impl TransitionRegistry {
      pub fn new() -> Self { Self { states: HashMap::new() } }
      pub fn get_or_create(&mut self, id: TransitionId) -> &mut TransitionState { ... }
      pub fn has_active_transitions(&self) -> bool { ... }
      pub fn cleanup_completed(&mut self) { ... } // Remove entries with no active tweens
  }
  ```

  Update `ora/src/animation/mod.rs` to add:
  ```rust
  pub mod transition;
  pub use transition::{TransitionId, TransitionSpec, TransitionConfig, TransitionState, TransitionRegistry};
  ```

  When creating/retargeting tweens in advance_* methods:
  - Use `std::time::Duration::from_millis(config.duration_ms as u64)` for duration
  - If no tween exists and target differs from default, create `Tween::new(current_or_default, target, duration, easing)` and call `.start()`
  - If tween exists and target changed, call `tween.retarget(new_target)`
  - If tween exists and target unchanged, just call `tween.update()` to advance time
  </action>
