    4. Create `crates/ora/src/app.rs`:
       - `pub struct App` with fields: title (String), size ((u32, u32)), on_open callback (Option<Box<dyn FnOnce(&mut AppContext)>>)
       - Builder methods: `new() -> Self` (defaults: "ora", 800x600), `title(self, impl Into<String>) -> Self`, `size(self, u32, u32) -> Self`, `on_open<F: FnOnce(&mut AppContext) + 'static>(self, F) -> Self`
       - `run(self) -> !` method that creates winit EventLoop, constructs OraApp (the ApplicationHandler), and calls `event_loop.run_app(&mut ora_app).unwrap(); std::process::exit(0);`

       - Re-export gpu and event_loop modules

    6. Create `crates/ora/src/platform/gpu.rs`:
       - `pub struct GpuState` holding: window (Arc<Window>), surface (wgpu::Surface<'static>), device (wgpu::Device), queue (wgpu::Queue), config (wgpu::SurfaceConfiguration), size ((u32, u32))
       - `pub async fn new(window: Arc<Window>) -> Self` that:
         - Creates wgpu::Instance with PRIMARY backends
         - Creates surface from window.clone()
         - Requests adapter with compatible_surface
         - Requests device and queue with default limits
         - Picks sRGB surface format (fallback to first available)
         - Configures surface with PresentMode::Fifo (vsync)
         - Guards against zero-size: if width or height is 0, use 1 as minimum
       - `pub fn resize(&mut self, width: u32, height: u32)` that guards width > 0 && height > 0 before reconfiguring surface
       - `pub fn render(&mut self) -> Result<(), wgpu::SurfaceError>` that:
         - Gets current texture
         - Creates command encoder
         - Begins render pass with dark background clear color (r: 0.1, g: 0.1, b: 0.12, a: 1.0)
         - Submits and presents (stub -- no actual drawing yet, just clear)

    7. Create `crates/ora/src/platform/event_loop.rs`:
       - `pub struct OraApp` holding: app_config (Option<App>), gpu_state (Option<GpuState>), entity_storage (EntityStorage)
       - Implement `winit::application::ApplicationHandler` for OraApp:
         - `resumed()`: Create window with title and size from app_config, wrap in Arc, init GpuState via `pollster::block_on(GpuState::new(window))`, call on_open callback if present (passing &mut AppContext wrapping the entity storage)
         - `window_event()`: Handle Resized (call gpu_state.resize), CloseRequested (exit event loop), RedrawRequested (call gpu_state.render, then request_redraw for continuous loop)
       - OraApp::new(app: App) constructor

    2. Create `crates/ora/src/entity/handle.rs`:
       - `pub struct Entity<T>` with fields: index (generational_arena::Index), _phantom (PhantomData<T>)
       - Derive Clone, Copy (Index is Copy, PhantomData is Copy)
       - Implement Debug manually to show type name
       - Entity<T> is a lightweight handle -- no methods beyond construction. All access goes through EntityStorage.
       - `pub(crate) fn new(index: generational_arena::Index) -> Self` constructor

    3. Create `crates/ora/src/entity/storage.rs`:
       - `pub struct EntityStorage` with field: arenas (HashMap<TypeId, Box<dyn Any>>)
       - Private helper `fn get_or_create_arena<T: 'static>(&mut self) -> &mut Arena<T>` that lazily creates typed arenas
       - Private helper `fn get_arena<T: 'static>(&self) -> Option<&Arena<T>>` for read access
       - Public API:
         - `pub fn new() -> Self`
         - `pub fn insert<T: 'static>(&mut self, value: T) -> Entity<T>` -- inserts into typed arena, returns Entity handle
         - `pub fn read<T: 'static>(&self, entity: &Entity<T>) -> &T` -- panics with "Entity<{type_name}> handle is invalid (dangling or removed)" if not found
         - `pub fn read_opt<T: 'static>(&self, entity: &Entity<T>) -> Option<&T>` -- fallible read
         - `pub fn update<T: 'static, R>(&mut self, entity: &Entity<T>, f: impl FnOnce(&mut T) -> R) -> R` -- gets &mut T from arena, calls closure, returns result. Panics if entity not found.
         - `pub fn remove<T: 'static>(&mut self, entity: &Entity<T>) -> Option<T>` -- removes from arena
       - Use `std::any::{Any, TypeId}` and `std::collections::HashMap` for type-erased arena map
       - Use `generational_arena::Arena` as the underlying storage per type

    4. Wire entity module into lib.rs (should already be declared from Task 1, just ensure it compiles).

    5. Create a minimal AppContext struct in a new file `crates/ora/src/context.rs` (or inline in app.rs):
