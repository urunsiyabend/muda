  <action>
    1. Create `crates/ora/src/element/trait_def.rs`:
       - Define the Element trait:
         ```rust
         pub trait Element: 'static {
             /// State persisted between frames, produced during layout.
             type RequestLayoutState;

             /// Compute layout requirements. Called first in the lifecycle.
             /// Returns state that will be passed to prepaint and paint.
             fn request_layout(
                 &mut self,
                 cx: &mut LayoutContext,
             ) -> (LayoutId, Self::RequestLayoutState);

             /// Register hitboxes and prepare for painting.
             /// Called after layout is resolved, before paint.
             fn prepaint(
                 &mut self,
                 state: &mut Self::RequestLayoutState,
                 cx: &mut PrepaintContext,
             );

             /// Produce GPU rendering commands.
             /// Called last, produces the visual output.
             fn paint(
                 &mut self,
                 state: &mut Self::RequestLayoutState,
                 cx: &mut PaintContext,
             );
         }
         ```
       - Define stub context types in this file for now (will be fleshed out in Task 2 and Plan 03):
         - `pub struct LayoutContext` -- placeholder with entity_storage reference
         - `pub struct PrepaintContext` -- placeholder
         - `pub struct PaintContext` -- placeholder
       - Define `pub struct LayoutId(pub(crate) usize)` -- opaque handle to layout data (real layout engine comes in Phase 2)

    2. Create `crates/ora/src/element/any_element.rs`:
       - Define internal trait for type erasure:
         ```rust
         pub(crate) trait ElementObject {
             fn request_layout(&mut self, cx: &mut LayoutContext) -> LayoutId;
             fn prepaint(&mut self, cx: &mut PrepaintContext);
             fn paint(&mut self, cx: &mut PaintContext);
         }
         ```
       - Implement `ElementObject` for any `(E, Option<E::RequestLayoutState>)` where `E: Element`:
         - `request_layout`: calls E::request_layout, stores state in the Option, returns LayoutId
         - `prepaint`: calls E::prepaint with stored state
         - `paint`: calls E::paint with stored state
       - Define `pub struct AnyElement { inner: Box<dyn ElementObject>, children: Vec<AnyElement> }`
       - AnyElement methods:
         - `pub fn new<E: Element>(element: E) -> Self` -- wraps element in type-erased box
         - `pub fn with_children(mut self, children: Vec<AnyElement>) -> Self`
         - `pub(crate) fn request_layout(&mut self, cx: &mut LayoutContext) -> LayoutId`
         - `pub(crate) fn prepaint(&mut self, cx: &mut PrepaintContext)`
         - `pub(crate) fn paint(&mut self, cx: &mut PaintContext)`
       - Children lifecycle: when AnyElement's lifecycle methods are called, it processes its own element first, then recursively calls the same phase on each child. This ensures all elements go through each phase in tree order.
       - Implement `From<E> for AnyElement where E: Element` for ergonomic conversion.

    3. Create `crates/ora/src/element/mod.rs`:
       - Declare pub modules: trait_def, any_element
       - Re-export Element, AnyElement, LayoutId, LayoutContext, PrepaintContext, PaintContext

    4. Create `crates/ora/src/view/trait_def.rs`:
       - Define the View trait:
         ```rust
         pub trait View: 'static + Sized {
             fn render(&self, cx: &mut ViewContext<Self>) -> AnyElement;
         }
         ```
       - ViewContext<V> is generic over the View type for typed access to self.
       - NOTE: ViewContext is defined in context.rs (Task 2). Forward-declare or use a simpler signature here if circular dependency issues arise: `fn render(&self, cx: &mut ViewContext) -> AnyElement` (non-generic ViewContext is acceptable for Phase 1; generic can come later).
       - Define `pub(crate) trait AnyView` for type erasure of views:
         ```rust

             fn render(&self, cx: &mut ViewRenderContext) -> AnyElement;
         }
         ```
       - ViewRenderContext is a non-generic rendering context that AnyView uses internally.

    5. Create `crates/ora/src/view/mod.rs`:
