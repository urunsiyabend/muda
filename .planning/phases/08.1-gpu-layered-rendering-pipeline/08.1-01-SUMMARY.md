- Fixed `render()` signature from `RenderPass<'a>` to `RenderPass<'_>`, breaking the lifetime coupling that prevented multi-pass rendering

## Decisions Made

- Used `RenderPass<'_>` (Rust lifetime elision) rather than an explicit named lifetime - this is the standard Rust idiom for "this reference has some lifetime but I don't constrain it to match anything else". Safe because GPU objects (pipeline, bind_group) all live on `GpuState` which outlives any render pass within a frame.
- Added `render_range()` as a separate method rather than modifying `render()` with an optional range parameter - cleaner API; callers that want all instances use `render()`, callers doing layer-based subset drawing use `render_range()`.
- `instance_count()` returns `u32` (not `usize`) to directly match the wgpu `draw()` API's `instance_range: Range<u32>` parameter type, avoiding casts at call sites.
