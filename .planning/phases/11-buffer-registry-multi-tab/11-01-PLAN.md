<task type="auto">
  <name>Task 1: Add Buffer Registry, tab_order, and mru_stack fields to Workspace</name>
  <files>core_editor/src/domain/workspace.rs</files>
  <action>
Add three new fields to the Workspace struct:

1. `path_to_doc: HashMap<PathBuf, DocumentId>` - maps canonical file paths to document IDs for deduplication.
2. `tab_order: Vec<ViewId>` - maintains visual tab strip order (insertion order).
3. `mru_stack: Vec<ViewId>` - tracks activation history, front = most recent.

Add `use std::path::PathBuf;` import.

Initialize all three as empty in `new()`.

Modify these methods:

**open_document(path)**:
- Canonicalize path with `std::fs::canonicalize(path).unwrap_or_else(|_| path.to_path_buf())`.
- Look up canonical path in `path_to_doc`. If found, return `Ok(existing_doc_id)` — change return type to `std::io::Result<(DocumentId, bool)>` where bool = was_existing.
- If not found, create Document as before, insert into `path_to_doc`.
- This is a signature change. All callers must be updated.

**create_view(doc_id)**:
- After inserting into `views` HashMap, insert the new ViewId into `tab_order` after the current active tab position. If no active tab, push to end.
- Push to front of `mru_stack`.
- Still set as active_view_id.

**close_view(view_id)**:
- Remove from `tab_order` and `mru_stack`.
- When selecting new active view after closing active: use `mru_stack[0]` (first remaining entry) instead of random HashMap key.

**close_document_force(doc_id)**:
- Remove canonical path from `path_to_doc` when closing document. Get the path from `self.documents.get(&doc_id)` before removing.
- The existing code already calls `close_view` for associated views, which handles tab_order/mru_stack cleanup.
- When selecting new active after close: use `mru_stack.first()` instead of `self.views.keys().next()`.

**set_active_view(view_id)**:
- Promote view_id to front of `mru_stack` (remove if present, then insert at index 0).

**with_new_document()**:
- Update to handle the unchanged `create_document` (which has no path, so no path_to_doc entry needed).

Add public accessors:
- `pub fn tab_order(&self) -> &[ViewId]` - returns tab order slice.
- `pub fn mru_stack(&self) -> &[ViewId]` - returns MRU stack slice.

Update ALL existing callers of `open_document` in workspace.rs tests and anywhere else that calls it to handle the new `(DocumentId, bool)` return type.

Key invariant: Every ViewId in `views` HashMap exists exactly once in `tab_order`.
