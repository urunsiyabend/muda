Launch the editor with a directory: `cargo run -p wgpu_client -- path/to/some/directory`

**TAB-01: Buffer deduplication**

2. Try to open the same file again
3. Verify: No duplicate tab appears. The existing tab is activated.

**TAB-02: Tab switching with state preservation**
1. Open two different files in tabs
2. In file A, scroll down and type some text
3. Click tab for file B
4. Click tab for file A
5. Verify: File A shows the same scroll position and cursor position you left

**TAB-02b: Keyboard tab switching**
6. Press Ctrl+Tab — verify next tab activates
7. Press Ctrl+Shift+Tab — verify previous tab activates
8. Press Ctrl+Tab multiple times — verify it wraps around

**TAB-03: Tab closing**
9. With a clean (saved) file active, press Ctrl+W
10. Verify: Tab closes, next MRU tab becomes active
11. Open a file, type something (make it dirty)
12. Press Ctrl+W
13. Verify: Save/Discard/Cancel dialog appears
14. Click Cancel — verify tab stays open
15. Press Ctrl+W again, click Discard — verify tab closes

**TAB-05: Dirty indicator**
16. Open a clean file — verify no dot before filename
17. Type a character — verify dot appears before filename in tab
18. Save (Ctrl+S if file has path) — verify dot disappears

**Visual checks:**
19. Verify active tab has a colored bottom border (accent color)
20. Verify inactive tabs have no bottom border accent
21. Verify clicking X button on a tab closes it
22. Verify middle-clicking a tab closes it

**Edge cases:**
23. Close all tabs — verify empty state (no crash, some placeholder shown)
24. Open a new file after closing all tabs — verify it works
