Add two new public methods to App:

**App::switch_tab(view_id: u64)**:
- Convert u64 to ViewId (ViewId wraps u64 — check how ViewId is constructed).
- Call `self.workspace.set_active_view(view_id)` directly. Do NOT call `can_switch_active()` — per CONTEXT and RESEARCH, can_switch_active shows a dialog and must NOT be used during tab switching.
- Set `self.needs_render = true`.

**App::switch_tab_relative(offset: i32)**:
- Get current active_view_id from workspace.
- Get tab_order from workspace.
- Find current position in tab_order.
- Calculate new index with wrapping: `(current + offset).rem_euclid(len)`.
- Call `self.workspace.set_active_view(new_view_id)`.
- Set `self.needs_render = true`.
- This handles both Ctrl+Tab (offset=+1) and Ctrl+Shift+Tab (offset=-1).

**App::close_active_tab()**:
- Get active_view_id. If None, return.
- Get the document_id from the active view.
- Call `self.workspace.close_document_protected(doc_id)`.
- If Ok: document and views are closed. MRU fallback already handled by workspace. Set needs_render.
- If Err(ProtectionError::UnsavedChanges(unsaved)): Set `self.pending_action = Some(PendingAction::CloseDocument(doc_id))` and `self.pending_error = Some(ProtectionError::UnsavedChanges(unsaved))`. This triggers the save/discard/cancel dialog through the existing dialog machinery.
- Set `self.needs_render = true`.

**In wgpu_client/src/adapter.rs — CommandDispatcher::dispatch_command:**

Remove SwitchTab, SwitchTabPrev, and CloseTab from the stub handler block. Add real handling BEFORE the stub block:

```rust
EditorCommand::SwitchTab(0) => {
    // Ctrl+Tab: cycle to next tab in visual order
    self.app.switch_tab_relative(1);
    return;
}
EditorCommand::SwitchTab(view_id) => {
    // Click on specific tab
    self.app.switch_tab(view_id);
    return;
}
EditorCommand::SwitchTabPrev => {
    // Ctrl+Shift+Tab: cycle to previous tab
    self.app.switch_tab_relative(-1);
    return;
}
EditorCommand::CloseTab => {
    self.app.close_active_tab();
    return;
}
```

Also add `SwitchTabPrev` to the `to_core_command` match arm that returns None (alongside the other stub commands that don't map to core commands).

**In ora/src/events/editor_input.rs — translate_editor_command:**

Add Ctrl+Shift+Tab handling. The existing code handles `Key::Named(NamedKey::Tab) if ctrl` and returns `SwitchTab(0)`. Change this to also check shift:

```rust
Key::Named(NamedKey::Tab) if ctrl && shift => {

}
```

The shift+ctrl case MUST come before the ctrl-only case in the match arms to be matched first.
