  <action>
    1. Create gutter.rs implementing GutterView struct:
       - Calculate width dynamically: LEFT_PADDING + (digit_count × char_width) + separator_padding
       - Use GutterModel.line_number_width() for digit count (already in core_editor)

    2. Implement helper: calculate_width(gutter: &GutterModel, char_width: f32) -> f32
       - LEFT_PADDING = 8.0
       - digit_count = gutter.line_number_width()
       - separator_padding = 16.0 (space + separator char width)
       - Return: LEFT_PADDING + (digit_count as f32 × char_width) + separator_padding

    3. Implement View::render() consuming visible_lines from RenderModel:
       - Background: theme.color(ColorToken::BgSecondary)
       - For each line in visible_lines:
         - Right-align line number with appropriate width
         - If is_current_line: use ColorToken::FgPrimary (brighter)
         - Otherwise: use ColorToken::FgMuted (dimmer)
         - Include separator "│" after number
       - Use TextElement with FontFamily::Code (monospace)

    4. Pattern for line number rendering:
       ```rust
       for line in visible_lines {
           let color = if line.is_current_line {
               theme.color(ColorToken::FgPrimary)
           } else {
               theme.color(ColorToken::FgMuted)
           };

           // Each line row
           Div::new()
               .flex_row()
               .justify_end()  // Right-align
               .child(TextElement::new(format!("{}", line.line_number))
                   .size(TextSize::Body)
                   .color(color))
               .child(TextElement::new(" │")
                   .color(theme.color(ColorToken::BorderDefault)))
       }
       ```

    5. Export GutterView from views/mod.rs and ora/src/lib.rs

    CONTEXT decision: Current line highlight spans gutter AND editor area.
