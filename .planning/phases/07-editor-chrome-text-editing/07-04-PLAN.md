  <name>Task 1: Create CaretElement with blink logic</name>
  <files>ora/src/elements/caret.rs, ora/src/elements/mod.rs, ora/src/lib.rs</files>
  <action>
    1. Create caret.rs implementing CaretElement as an Element (not View):
       - Fields:
         - blink_visible: bool
         - last_blink: Instant
         - last_activity: Instant
         - blink_rate: Duration (default 500ms)
         - x: f32, y: f32 (position)
         - height: f32 (line height for caret height)

    2. Constants (RESEARCH.md Pattern 2):
       ```rust
       const BLINK_RATE: Duration = Duration::from_millis(500);
       const ACTIVITY_TIMEOUT: Duration = Duration::from_millis(500);
       const CARET_WIDTH: f32 = 2.0;  // Thin beam style per CONTEXT
       ```

    3. Implement methods:
       ```rust
       pub fn new(x: f32, y: f32, height: f32) -> Self

       pub fn on_activity(&mut self) {
           self.last_activity = Instant::now();
           self.blink_visible = true;  // Solid during typing
       }

       pub fn update(&mut self) -> bool {
           let now = Instant::now();

           // Don't blink if recently active
           if now.duration_since(self.last_activity) < Self::ACTIVITY_TIMEOUT {
               return false;
           }

           // Toggle blink
           if now.duration_since(self.last_blink) >= self.blink_rate {
               self.blink_visible = !self.blink_visible;
               self.last_blink = now;
               return true;  // Request redraw
           }
           false
       }

       pub fn set_position(&mut self, x: f32, y: f32) {
           self.x = x;
           self.y = y;
       }
       ```

    4. Implement Element trait:
       - request_layout: return fixed size (CARET_WIDTH × height)
       - prepaint: empty (caret doesn't need hitbox)
       - paint: if blink_visible, draw rectangle at position
         - Color: theme.color(ColorToken::AccentPrimary) or specific Caret token

    5. Export from elements/mod.rs and lib.rs

    Note: Blink update() should be called from frame loop or timer, not during render.
  </action>

    2. Implement TextStyle to ColorToken mapping helper:
       ```rust
       fn map_style_to_color(&self, style: TextStyle, theme: &Theme) -> Color {
           use core_editor::view_model::TextStyle;
           match style {
               TextStyle::Normal => theme.color(ColorToken::FgPrimary),
               TextStyle::Keyword => theme.color(ColorToken::SyntaxKeyword),
               TextStyle::String => theme.color(ColorToken::SyntaxString),
               TextStyle::Comment => theme.color(ColorToken::SyntaxComment),
               TextStyle::Type => theme.color(ColorToken::SyntaxType),
               TextStyle::Function => theme.color(ColorToken::SyntaxFunction),
               TextStyle::Number => theme.color(ColorToken::SyntaxNumber),
               TextStyle::Operator => theme.color(ColorToken::FgSecondary),
               TextStyle::Punctuation => theme.color(ColorToken::FgMuted),
               TextStyle::Constant => theme.color(ColorToken::SyntaxConstant),
               TextStyle::Variable => theme.color(ColorToken::FgPrimary),
               TextStyle::Module => theme.color(ColorToken::SyntaxType),
               TextStyle::Attribute => theme.color(ColorToken::SyntaxAttribute),
               TextStyle::Macro => theme.color(ColorToken::SyntaxMacro),
               TextStyle::Selection => theme.color(ColorToken::Selection),
               TextStyle::Error => theme.color(ColorToken::Error),
               TextStyle::Warning => theme.color(ColorToken::Warning),
               TextStyle::LineNumber | TextStyle::CurrentLineNumber => theme.color(ColorToken::FgMuted),
           }
       }
       ```

    3. Implement View::render():
       - Div.relative() container with overflow handling (CONTEXT: no wrap, horizontal scroll)
       - Layer structure:
         1. Current line background (full width)
         2. Selection backgrounds (solid, not semi-transparent per CONTEXT)
         3. Text content (syntax highlighted spans)
         4. Caret element (on top)

       Pattern (RESEARCH.md Pattern 5):
       ```rust
       Div::new()
           .relative()
           .w(pct(100.0))
           .h(pct(100.0))
           .child(self.render_current_line_bg(model, theme))
           .children(self.render_selection_rects(model, theme))
           .children(self.render_text_lines(model, theme))
           .child(CaretElement::new(...))
           .into()
       ```

    4. render_current_line_bg(model, theme):
       - Find current line index from visible_lines
       - Render full-width Div at that line's y position
       - Background: theme.color(ColorToken::CurrentLineBg) or similar

    5. render_selection_rects(model, theme):
       - Iterate visible_lines, find spans with TextStyle::Selection
       - For each selection span, render Div with:
         - Absolute position (x_offset, y_offset)
         - Size (span.width, line_height)
         - Background: theme.color(ColorToken::Selection) — SOLID, not semi-transparent

    6. render_text_lines(model, theme):
       - For each line in visible_lines:
         - Div.flex_row() for the line
         - For each span in line.spans:
           - TextElement with map_style_to_color(span.style)
           - Use FontFamily::Code (monospace)

    7. Export TextAreaView from views/mod.rs and lib.rs

    Note: Position calculations (x_offset, y_offset) need line_height from theme.
    Selection spans might need separate rendering from text spans.
