5. In `build_render_model`, ENTIRELY REPLACE the existing `pending.take()` block. Find this code:
   ```rust
   let pending = unsafe {
       &mut (*(self as *const CoreEditorAdapter as *mut CoreEditorAdapter)).pending_status_message
   };
   if let Some(msg) = pending.take() {
       render_model.status.message = Some(msg);
   }
   ```

   Replace it with:
   ```rust

       &mut (*(self as *const CoreEditorAdapter as *mut CoreEditorAdapter))
   };
   if let Some(ref msg) = self_mut.pending_status_message {
       if self_mut.status_message_expiry.map_or(false, |exp| Instant::now() < exp) {
           render_model.status.message = Some(msg.clone());
       } else {
           // Expired — clear both
           self_mut.pending_status_message = None;
           self_mut.status_message_expiry = None;
       }
   }
   ```

   Do NOT keep the old `pending.take()` code. The new block replaces it entirely.

6. Implement `status_message_expiry()` on the `FileOpDataSource` impl block for `CoreEditorAdapter`:
   ```rust

   }
   ```

**B. Add `status_message_expiry()` to the `FileOpDataSource` trait in `ora/src/editor_adapter/mod.rs`:**

Add this method to the trait (after `last_opened_directory`):
```rust
/// Returns the instant at which the current status message should expire.
///
/// Used by the event loop to schedule a wake-up for clearing the message.
fn status_message_expiry(&self) -> Option<std::time::Instant>;
```

**C. Update `about_to_wait` in `ora/src/platform/event_loop.rs`:**

In the `else` branch of `about_to_wait` (the sleep-scheduling branch, lines ~780-800), REPLACE the existing `match self.next_blink_instant { ... }` block with unified wake scheduling that considers both blink and status message expiry:

```rust
let mut earliest_wake: Option<Instant> = self.next_blink_instant;
if let Some(adapter) = &self.editor_adapter {
    if let Some(expiry) = adapter.borrow().status_message_expiry() {
        earliest_wake = Some(match earliest_wake {
            Some(existing) => existing.min(expiry),
            None => expiry,
        });
    }
}
match earliest_wake {
    Some(instant) if instant > Instant::now() => {
        event_loop.set_control_flow(ControlFlow::WaitUntil(instant));
    }
    Some(_) => {
        // Past due — request redraw immediately
        if let Some(gpu_state) = &self.gpu_state {
            gpu_state.window.request_redraw();
        }
        // Advance blink if it was the one that expired
        if self.next_blink_instant.map_or(false, |i| i <= Instant::now()) {
            self.next_blink_instant = Some(Instant::now() + BLINK_RATE);
        }
        event_loop.set_control_flow(ControlFlow::WaitUntil(
            earliest_wake.unwrap_or_else(|| Instant::now() + BLINK_RATE)
        ));
    }
    None => {
        event_loop.set_control_flow(ControlFlow::Wait);
    }
}
```

This replaces the entire existing `match self.next_blink_instant { ... }` block (lines ~781-799). The blink behavior is preserved — the only addition is that `status_message_expiry` is considered as another wake-up source.
