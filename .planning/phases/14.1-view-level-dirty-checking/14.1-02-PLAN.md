**Part A: Split scroll handling by consumer**

In the MouseWheel handler (~line 907-961), the scroll event is first dispatched to hitbox handlers (ScrollArea for sidebar). If `consumed == true`, sidebar handled the scroll. If `consumed == false`, editor scroll runs.

Change the unconditional `self.needs_layout = true` at line 958 to be conditional:

```rust
// After the scroll handling block:
if consumed {
    // Sidebar scroll changes visible items in virtualized file tree.
    // Viewport virtualization adds/removes elements → LayoutId count changes → needs full layout.
    self.needs_layout = true;
} else {
    // Editor scroll: after Plan 01, element tree structure is layout-stable.
    // visible_lines count = viewport_lines (set on resize only).
    // Fractional offset applied via push_offset in paint, not mt() in layout.
    // → No layout mutation, reuse cached layout_outputs.
    // needs_layout stays false (or whatever it was before).
}
```

**Part B: Add FrameDirtyFlags struct**

Add a `FrameDirtyFlags` struct to event_loop.rs (can be a simple struct with pub(crate) fields):

```rust
/// Which UI regions need re-rendering this frame.
/// Used to track what changed so future paint caching can skip unchanged views.
#[derive(Debug, Default)]
struct FrameDirtyFlags {
    /// Editor text/gutter content changed (scroll_y, file edit, selection).
    pub editor_content: bool,
    /// Tab bar changed (tab open/close/switch/rename/dirty indicator).
    pub tab_bar: bool,
    /// Status bar changed (cursor move, file save, syntax).
    pub status_bar: bool,
    /// Sidebar changed (tree expand/collapse, file add/remove, sidebar scroll).
    pub sidebar: bool,
}
```

Add `dirty_flags: FrameDirtyFlags` field to the event loop struct. Reset it at the start of each RedrawRequested.

Wire the dirty flags in the event handlers:
- **MouseWheel (editor scroll, not consumed):** `dirty_flags.editor_content = true` (content lines change)
- **MouseWheel (sidebar scroll, consumed):** `dirty_flags.sidebar = true`
- **KeyboardInput (editor command):** `dirty_flags.editor_content = true; dirty_flags.status_bar = true`
- **KeyboardInput (action — tab switch, file ops):** all flags true
- **Resize:** all flags true
- **has_dirty_entities:** all flags true
- **Watcher events:** `dirty_flags.sidebar = true; dirty_flags.tab_bar = true`
- **Mouse click:** `dirty_flags.editor_content = true; dirty_flags.status_bar = true; dirty_flags.tab_bar = true`
- **Focus change:** `dirty_flags.editor_content = true` (selection dimming)

For now, FrameDirtyFlags is informational — it doesn't gate rendering yet (paint caching is future work or a separate plan). The main functional change is the conditional `needs_layout` on scroll.
