<task type="auto">
  <name>Task 1: Create style unit types and style struct</name>
  <files>ora/src/style/units.rs, ora/src/style/mod.rs</files>
  <action>
Create `ora/src/style/` module with two files:

**ora/src/style/units.rs** — Fundamental measurement types:
- `Length` enum: `Px(f32)`, `Percent(f32)`, `Auto` — CSS-like sizing. Implement `Default` as `Auto`.
- `Edges<T>` struct: `top: T, right: T, bottom: T, left: T` — for padding, margin, border widths. Implement `Edges::all(v)`, `Edges::xy(x, y)`, `Edges::zero()`. Derive `Debug, Clone, Copy, PartialEq, Default`.
- `Corners<T>` struct: `top_left: T, top_right: T, bottom_right: T, bottom_left: T` — for border-radius. Implement `Corners::all(v)`, `Corners::zero()`. Derive `Debug, Clone, Copy, PartialEq, Default`.
- `Size<T>` struct: `width: T, height: T`. Derive same traits. Implement `Size::new(w, h)`.
- `Point<T>` struct: `x: T, y: T`. Derive same traits. Implement `Point::new(x, y)`.
- `Rect` struct: `origin: Point<f32>, size: Size<f32>`. Implement `Rect::new(x, y, w, h)`, `Rect::zero()`, `Rect::intersect(&self, other: &Rect) -> Rect` (for scissor clipping). Derive `Debug, Clone, Copy, PartialEq, Default`.

**ora/src/style/mod.rs** — Style types and the Style struct:
- `pub mod units;` and re-export all unit types.
- `Color` struct: `r: f32, g: f32, b: f32, a: f32` (RGBA floats 0.0..1.0). Implement `Color::rgb(r,g,b)`, `Color::rgba(r,g,b,a)`, `Color::transparent()`, `Color::white()`, `Color::black()`, `Color::to_array(&self) -> [f32; 4]`. Derive `Debug, Clone, Copy, PartialEq, Default` (default = transparent).
- `Gradient` struct: `start: Color, end: Color, angle_radians: f32`. Derive same traits.
- `Background` enum: `None`, `Solid(Color)`, `Linear(Gradient)`. Default = `None`.
- `Border` struct: `widths: Edges<f32>, color: Color`. Default = zero widths, transparent.
- `BoxShadow` struct: `offset_x: f32, offset_y: f32, blur: f32, spread: f32, color: Color`. Default = all zeros, transparent.
- `Overflow` enum: `Visible`, `Hidden`, `Scroll`. Default = `Visible`.
- `FlexDirection` enum: `Row`, `Column`. Default = `Row`.
- `JustifyContent` enum: `Start`, `Center`, `End`, `SpaceBetween`. Default = `Start`.
- `AlignItems` enum: `Start`, `Center`, `End`, `Stretch`. Default = `Stretch`.
- `AlignSelf` enum: `Auto`, `Start`, `Center`, `End`, `Stretch`. Default = `Auto`.
- `Position` enum: `Relative`, `Absolute`. Default = `Relative`.
- `Display` enum: `Flex`, `None`. Default = `Flex`.
- `Style` struct containing ALL properties:
  - `display: Display`
  - `position: Position`
  - `flex_direction: FlexDirection`
  - `justify_content: JustifyContent`
  - `align_items: AlignItems`
  - `align_self: AlignSelf`
  - `flex_grow: f32` (default 0.0)
  - `flex_shrink: f32` (default 1.0 — CRITICAL: match CSS default per RESEARCH.md pitfall 6)
  - `flex_basis: Length` (default Auto)
  - `width: Length`, `height: Length` (default Auto)
  - `min_width: Length`, `max_width: Length`, `min_height: Length`, `max_height: Length` (min defaults Auto, max defaults Auto)
  - `padding: Edges<f32>` (default zero)
  - `margin: Edges<f32>` (default zero)
  - `gap: f32` (default 0.0)
  - `top: Length`, `right: Length`, `bottom: Length`, `left: Length` (for absolute positioning, default Auto)
  - `background: Background`
  - `border: Border`
  - `border_radius: Corners<f32>` (per-corner, default zero)
  - `box_shadow: Option<BoxShadow>` (default None)
  - `overflow: Overflow`
  - `overflow_y: Overflow` (independent vertical overflow)
  - `scroll_offset: Point<f32>` (default zero, for scroll containers)
  Derive `Debug, Clone, PartialEq`. Implement `Default` with CSS-matching defaults (especially `flex_shrink: 1.0`).

All types must be `pub`. Do NOT add bytemuck derives to style types — those go on GPU-specific structs in the rendering module.
  </action>

- `LayoutInput` struct: `available_width: AvailableSpace, available_height: AvailableSpace` — what the parent provides to a child during layout. Implement `LayoutInput::new(w, h)`, `LayoutInput::definite(w, h)`. Default = MinContent for both.
- `LayoutOutput` struct: `bounds: crate::style::units::Rect` — computed position and size for an element after layout. Implement `LayoutOutput::new(bounds)`, `LayoutOutput::zero()`. Derive `Debug, Clone, Copy, PartialEq, Default`.

- `pub mod constraints;` with re-exports of `AvailableSpace`, `LayoutInput`, `LayoutOutput`.
