**TextSystem struct:**
```rust
pub struct TextSystem {
    font_system: glyphon::FontSystem,
    swash_cache: glyphon::SwashCache,
    cache: glyphon::Cache,
    atlas: glyphon::TextAtlas,
    text_renderer: glyphon::TextRenderer,
    // Collected text areas for batch rendering
    pending_buffers: Vec<TextEntry>,
}

struct TextEntry {
    buffer: glyphon::Buffer,
    left: f32,
    top: f32,
    bounds_left: i32,
    bounds_top: i32,
    bounds_right: i32,
    bounds_bottom: i32,
    default_color: glyphon::Color,
}
```

**TextSystem::new(device, queue, surface_format) -> Self:**
- Create FontSystem: `glyphon::FontSystem::new()` (loads system fonts)
- Create SwashCache: `glyphon::SwashCache::new()`
- Create Cache: `glyphon::Cache::new(device)`
- Create TextAtlas: `glyphon::TextAtlas::new(device, queue, &cache, surface_format)`
- Create TextRenderer: `glyphon::TextRenderer::new(&mut atlas, device, wgpu::MultisampleState::default(), None)`
- Initialize pending_buffers as empty Vec

**TextSystem::measure_text(...) -> Size<f32>:**
```rust
pub fn measure_text(
    &mut self,
    text: &str,
    font_size: f32,
    line_height: f32,
    max_width: Option<f32>, // None = no wrap, Some(w) = wrap at w
) -> (glyphon::Buffer, Size<f32>)
```
- Create Metrics from font_size and line_height
- Create Buffer with metrics
- Set buffer size: `buffer.set_size(&mut self.font_system, max_width, None)`
- Set text: `buffer.set_text(&mut self.font_system, text, glyphon::Attrs::new(), glyphon::Shaping::Advanced)`
- Shape: `buffer.shape_until_scroll(&mut self.font_system, false)`
- Measure: iterate `buffer.layout_runs()` to find max width and total height
- Return (buffer, Size { width, height })

CRITICAL (from RESEARCH.md Pitfall 4): The SAME Buffer must be used for measurement AND rendering. Return the Buffer so it can be stored in element state and passed back during paint.

**TextSystem::add_text_area(...):**
```rust
pub fn add_text_area(
    &mut self,
    buffer: glyphon::Buffer,
    left: f32,
    top: f32,
    clip_bounds: Rect, // From scissor/parent bounds
    color: Color,
)
```
- Convert Color to glyphon::Color (0-255 u8 RGBA)
- Store as TextEntry in pending_buffers

**TextSystem::prepare(&mut self, device, queue, window_width, window_height) -> Result:**
- Build Vec<TextArea> from pending_buffers (borrowing each buffer)
- Call `self.text_renderer.prepare(device, queue, &mut self.font_system, &mut self.atlas, &Resolution { width: window_width, height: window_height }, text_areas, &mut self.swash_cache)?`
- Return Ok(())

**TextSystem::render<'a>(&'a self, render_pass: &mut RenderPass<'a>) -> Result:**
- Call `self.text_renderer.render(&self.atlas, render_pass)?`
- Return Ok(())

**TextSystem::clear(&mut self):**
- Clear pending_buffers
- Call `self.atlas.trim()` to free unused atlas space

**TextSystem::font_system_mut(&mut self) -> &mut FontSystem:**
- Provide access for elements that need to do their own text operations
