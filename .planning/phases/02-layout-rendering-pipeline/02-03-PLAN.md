  <name>Task 1: Create WGSL shader for styled rectangles</name>
  <files>ora/src/rendering/shaders/rect.wgsl</files>
  <action>
Create `ora/src/rendering/shaders/` directory and `rect.wgsl` shader file.

**Vertex Shader:**
- Input: vertex_index (0..5 for two triangles forming a quad)
- Instance data via storage buffer or vertex attributes:
  ```wgsl
  struct RectInstance {
      // Rectangle geometry
      position: vec2<f32>,    // Top-left position in pixels
      size: vec2<f32>,        // Width, height in pixels
      // Visual properties
      color: vec4<f32>,       // Background RGBA
      border_color: vec4<f32>,// Border RGBA
      border_widths: vec4<f32>, // top, right, bottom, left
      corners: vec4<f32>,     // TL, TR, BR, BL border-radius
      // Shadow
      shadow_offset: vec2<f32>,
      shadow_blur: f32,
      shadow_spread: f32,
      shadow_color: vec4<f32>,
      // Gradient (if enabled)
      gradient_end_color: vec4<f32>, // If different from color, enables gradient
      gradient_angle: f32,
      // Viewport
      window_size: vec2<f32>,
      // Padding for alignment
      _pad: vec2<f32>,
  };
  ```
- Use vertex_index to compute quad corners: (0,0), (1,0), (0,1), (0,1), (1,0), (1,1)
- Scale by instance size, offset by instance position
- Convert pixel coordinates to NDC: x_ndc = (x / window_width) * 2.0 - 1.0; y_ndc = 1.0 - (y / window_height) * 2.0 (y is flipped in wgpu)
- For shadow: expand quad by shadow_blur + shadow_spread + abs(shadow_offset) on each side
- Output: clip position, local position (relative to rect center), instance data to fragment

**Fragment Shader:**
- Compute signed distance to rounded rectangle edge using standard SDF:
  ```wgsl
  fn rounded_rect_sdf(p: vec2<f32>, half_size: vec2<f32>, radius: f32) -> f32 {
      let q = abs(p) - half_size + vec2(radius);
      return min(max(q.x, q.y), 0.0) + length(max(q, vec2(0.0))) - radius;
  }
  ```
- Select corner radius based on quadrant (which corner the pixel is nearest to)
- **Background fill**: If distance < 0 (inside rect), use background color. Apply anti-aliasing with smoothstep at the edge (-0.5 to 0.5 pixel range).
- **Border**: If distance is between -border_width and 0, use border_color. Select per-side border width based on which edge is closest.
- **Shadow**: If shadow_blur > 0, compute shadow using closed-form error function approach (from RESEARCH.md Evan Wallace pattern). Shadow renders BEHIND the rectangle (lower alpha outside rect).
- **Gradient**: If gradient_end_color != color (check alpha or add a flag), interpolate between color and gradient_end_color based on rotated UV coordinate using gradient_angle.
- **Anti-aliasing**: Use fwidth() or smoothstep with 1px transition zone for all edges.

CRITICAL alignment notes (from RESEARCH.md Pitfall 2):
- vec3 aligns to 16 bytes in WGSL
- Use vec4 instead of vec3 everywhere to avoid alignment issues
- Use explicit padding fields where needed
- Struct must match Rust bytemuck layout exactly

   - `render_pass.draw(0..6, 0..self.instance_count)`
