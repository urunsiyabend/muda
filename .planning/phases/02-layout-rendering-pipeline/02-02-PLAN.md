Create `ora/src/layout/flexbox.rs` implementing a three-pass flexbox algorithm. The function signature:

```rust
pub fn compute_flexbox(
    styles: &[&Style],          // Indexed by node ID (0 = parent, 1..N = children)
    children_of: &[Vec<usize>], // children_of[i] = child indices of node i
    intrinsic_sizes: &[Option<Size<f32>>], // Pre-measured intrinsic sizes (e.g. text)
    root: usize,                // Root node index
    available: LayoutInput,     // Available space from parent
) -> Vec<LayoutOutput>          // Computed bounds for each node
```

**Three-Pass Algorithm (from RESEARCH.md):**

**Pass 1 — Resolve fixed sizes (top-down):**
For each node, resolve its width/height from Style:
- `Length::Px(v)` -> use v directly
- `Length::Percent(p)` -> if parent has definite dimension: parent_dim * p / 100.0, else treat as Auto
- `Length::Auto` -> mark as auto (will be computed in Pass 2 or 3)
- Apply min_width/max_width/min_height/max_height constraints (clamp)
- Subtract padding from available space for children (padding is inside the box)

**Pass 2 — Measure auto sizes (bottom-up):**
Starting from leaf nodes, compute intrinsic content sizes:
- Leaf with intrinsic_size set (text): use that
- Leaf with no children and Auto size: use 0 (will be stretched by flex)
- Container with children (Row): width = sum(child_widths) + gap*(N-1) + padding.left + padding.right; height = max(child_heights) + padding.top + padding.bottom
- Container with children (Column): height = sum(child_heights) + gap*(N-1) + padding.top + padding.bottom; width = max(child_widths) + padding.left + padding.right
- Only compute auto dimensions; definite dimensions from Pass 1 are kept

**Pass 3 — Distribute space and position (top-down):**
For each container node, distribute space among children:
1. Calculate total main-axis size of children (sum of their main-axis dimension + gaps)
2. Compare to container's main-axis inner size (size - padding)
3. If remaining > 0 and any child has flex_grow > 0: distribute proportionally (child_grow / total_grow * remaining)
4. If deficit < 0 and any child has flex_shrink > 0: shrink proportionally (child_shrink / total_shrink * deficit). CRITICAL: flex_shrink defaults to 1.0 per CSS.
5. Apply flex_basis: if not Auto, use as initial main-axis size before grow/shrink
6. Position children along main axis according to justify_content:
   - `Start`: pack at start
   - `Center`: center with equal space on both sides
   - `End`: pack at end
   - `SpaceBetween`: first at start, last at end, equal gaps between
7. Position children along cross axis according to align_items (or child's align_self if not Auto):
   - `Start`: align to cross-start
   - `Center`: center on cross axis
   - `End`: align to cross-end
   - `Stretch`: expand to fill cross axis (override child's cross-axis auto size)
8. Apply margin: offset child position by margin.left/margin.top, reduce available space by margin
9. For `Position::Absolute` children: position relative to parent using top/right/bottom/left offsets, do NOT include in flow

**Important constraints from CONTEXT.md:**
- No flex-wrap (single axis only)
- Child wins on size conflicts (don't shrink below content)
- align-self overrides align-items for individual children
