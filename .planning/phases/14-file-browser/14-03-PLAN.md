  3. Add imports:
     ```rust

     use notify::RecursiveMode;
     use std::sync::mpsc;
     ```

  4. Add fields to `CoreEditorAdapter`:
     ```rust
     /// Filesystem watcher debouncer — dropping stops watching.
     watcher: Option<Debouncer<notify::RecommendedWatcher, FileIdMap>>,
     /// Receiver for debounced filesystem events.
     watcher_rx: Option<mpsc::Receiver<DebounceEventResult>>,
     ```
     Initialize both to `None` in all constructors (`new()`, `open_file()`, `open_directory()`).

  5. Implement a private method `create_watcher(&mut self, path: &std::path::Path)`:
     ```rust
     fn create_watcher(&mut self, path: &std::path::Path) {
         // Drop existing watcher first
         self.watcher = None;
         self.watcher_rx = None;

         let (tx, rx) = mpsc::channel::<DebounceEventResult>();
         match new_debouncer(
             std::time::Duration::from_millis(300),
             None,
             move |res: DebounceEventResult| { let _ = tx.send(res); },
         ) {
             Ok(mut debouncer) => {
                 if let Err(e) = debouncer.watcher().watch(path, RecursiveMode::Recursive) {
                     log::warn!("Failed to watch {:?}: {:?}", path, e);
                     return;
                 }
                 log::info!("Filesystem watcher started for {:?}", path);
                 self.watcher = Some(debouncer);
                 self.watcher_rx = Some(rx);
             }
             Err(e) => {
                 log::warn!("Failed to create filesystem watcher: {:?}", e);
             }
         }
     }
     ```

  6. Implement `FileOpDataSource` methods:
     - `poll_watcher_events(&mut self) -> bool`: drain `self.watcher_rx` with `try_recv()` loop. If any `Ok(events)` received, call `self.app.sidebar.mark_tree_dirty()`, set `self.app.needs_render = true`, return `true`. Log warnings for `Err`. Return `false` if no events.
     - `start_watcher(&mut self, path: PathBuf)`: call `self.create_watcher(&path)`.
     - `stop_watcher(&mut self)`: set `self.watcher = None; self.watcher_rx = None;`

  7. In `open_directory()` constructor: after setting up the sidebar, call `create_watcher(&canonical_path)` to start watching immediately.

  8. In `handle_folder_opened()`: call `self.create_watcher(&canonical_path)` to restart the watcher on the new workspace root.
