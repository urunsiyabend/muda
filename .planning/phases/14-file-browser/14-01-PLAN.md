  <action>
  1. Add an `ignored_patterns: Vec<String>` field to the `Sidebar` struct. Default to `vec![".git".to_string()]`.

  2. Update `Sidebar::new()` to accept `ignored_patterns: Vec<String>` parameter and store it. Update `Default` impl to set `ignored_patterns: vec![".git".to_string()]`.

  3. Fix `read_dir_sorted` — change signature to `fn read_dir_sorted(dir: &PathBuf, ignored_patterns: &[String]) -> Vec<FileEntry>`. Replace the `name.starts_with('.')` filter with:
     ```rust
     if ignored_patterns.iter().any(|p| p == &name) {
         return None;
     }
     ```
     This means only entries matching an ignored pattern are hidden. Dotfiles like .env, .gitignore, .rustfmt.toml are now visible.

  4. Update all call sites of `read_dir_sorted` to pass `&self.ignored_patterns`:
     - `refresh_entries()` — `Self::read_dir_sorted(base_dir, &self.ignored_patterns)`
     - `build_tree_recursive()` — `Self::read_dir_sorted(dir, &self.ignored_patterns)`

  5. Add `pub fn auto_expand_first_level(&mut self)` method:
     ```rust
     pub fn auto_expand_first_level(&mut self) {
         if let Some(ref base) = self.base_directory {
             let entries = Self::read_dir_sorted(base, &self.ignored_patterns);
             for entry in &entries {
                 if entry.is_dir {
                     self.expanded_dirs.insert(entry.path.clone());
                 }
             }
             self.tree_dirty = true;
         }
     }
     ```

  6. Call `self.auto_expand_first_level()` at the end of `set_base_directory()`.

  7. Add a setter: `pub fn set_ignored_patterns(&mut self, patterns: Vec<String>) { self.ignored_patterns = patterns; self.tree_dirty = true; }`

  8. Add a public method `pub fn mark_tree_dirty(&mut self) { self.tree_dirty = true; }` for the watcher to use in later plans.

  9. Update existing tests. The `test_real_tree_expand` test currently expects dotfiles to be hidden — update expectations. Add a test that verifies ignored_patterns filtering works (create temp dir with .git and .env, confirm .git hidden but .env visible).
