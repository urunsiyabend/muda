Add a `WidgetSize` enum to `ora/src/elements/button.rs` (co-located with Button since Button is the first consumer and it avoids a new file for 20 lines of code):

```rust
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub enum WidgetSize {
    Sm,        // compact: height=24px, font=12px, padding_h=8px, padding_v=4px, border_radius=3px
    #[default]
    Md,        // standard: height=32px, font=13px, padding_h=12px, padding_v=6px, border_radius=4px
    Lg,        // prominent: height=40px, font=14px, padding_h=16px, padding_v=8px, border_radius=5px
}

impl WidgetSize {
    pub fn height(&self) -> f32 {
        match self { Self::Sm => 24.0, Self::Md => 32.0, Self::Lg => 40.0 }
    }
    pub fn font_size(&self) -> f32 {
        match self { Self::Sm => 12.0, Self::Md => 13.0, Self::Lg => 14.0 }
    }
    pub fn padding_h(&self) -> f32 {
        match self { Self::Sm => 8.0, Self::Md => 12.0, Self::Lg => 16.0 }
    }
    pub fn padding_v(&self) -> f32 {
        match self { Self::Sm => 4.0, Self::Md => 6.0, Self::Lg => 8.0 }
    }
    pub fn border_radius(&self) -> f32 {
        match self { Self::Sm => 3.0, Self::Md => 4.0, Self::Lg => 5.0 }
    }
}
```

Create `ora/src/elements/input.rs` implementing the Input widget (WIDGET-02).

Input is a composite element (like Button) that stores a TextElement internally for lifecycle control.

Structure:
```rust
pub struct Input {
    value: String,
    placeholder: String,
    size: WidgetSize,
    disabled: bool,
    focus_handle: Option<FocusHandle>,
    on_change: Option<Box<dyn Fn(&str) + 'static>>,
    // Internal text element for value/placeholder display
    text_element: Option<TextElement>,
}
```

Builder API:
- `input(placeholder: impl Into<String>) -> Input` — constructor function
- `Input::new(placeholder: String)` — creates input with empty value, Md size
- `.value(v: impl Into<String>)` — set current value
- `.size(s: WidgetSize)` — set size tier
- `.disabled(d: bool)` — disable input
- `.focusable(handle: FocusHandle)` — make focusable
- `.on_change(handler: impl Fn(&str) + 'static)` — change callback

State struct:
```rust
pub struct InputState {
    layout_id: LayoutId,
    text_layout_id: LayoutId,
    text_state: TextState,
    hitbox_id: Option<HitboxId>,
    focus_id: Option<FocusId>,
}
```

Element implementation:
1. `request_layout`: Create Style with padding from WidgetSize, border from 1px, min_height from WidgetSize. Create TextElement showing `self.value` if non-empty else `self.placeholder`. Use WidgetSize font_size. Request layout for both container and text child.
2. `prepaint`: Register hitbox (opaque), register focusable if focus_handle provided. Prepaint text child.
3. `paint`: Determine interaction state. Get theme colors:
   - bg: BgPrimary (normal), BgSecondary (disabled)
   - border: Accent (focused), Border (normal), BgSecondary (disabled)
   - text: FgPrimary (has value), FgMuted (showing placeholder)
   Apply borrow-safe pattern: complete mutable cx operations before cx.theme() reference (07-01 decision).
   Paint styled rect, update text color, paint text child.
   For disabled state: reduce alpha to 0.5 on bg and text colors (per CONTEXT: dimmed 50%).
