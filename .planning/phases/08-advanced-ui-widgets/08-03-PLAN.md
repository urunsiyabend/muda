**Checkbox** (WIDGET-03):

```rust
const CHECKBOX_SIZE_SM: f32 = 14.0;
const CHECKBOX_SIZE_MD: f32 = 18.0;
const CHECKBOX_SIZE_LG: f32 = 22.0;
const CHECKBOX_FONT_SM: f32 = 12.0;
const CHECKBOX_FONT_MD: f32 = 13.0;
const CHECKBOX_FONT_LG: f32 = 14.0;
const CHECKBOX_GAP: f32 = 8.0;  // gap between box and label
const CHECKBOX_BORDER_RADIUS: f32 = 3.0;

pub struct Checkbox {
    label: String,
    checked: bool,
    disabled: bool,
    size: CheckboxSize,  // Sm/Md/Lg local enum (or WidgetSize if available)
    on_change: Option<Box<dyn Fn(bool) + 'static>>,
    focus_handle: Option<FocusHandle>,
    label_element: Option<TextElement>,
    check_element: Option<TextElement>,  // "checkmark" character
}
```

Use a local `CheckboxSize` enum if WidgetSize is not yet available:
```rust
#[derive(Clone, Copy, Debug, Default)]
pub enum CheckboxSize { Sm, #[default] Md, Lg }
```

Builder API:
- `checkbox(label: impl Into<String>) -> Checkbox`
- `.checked(bool)` — set checked state
- `.disabled(bool)` — disable
- `.on_change(handler: impl Fn(bool) + 'static)` — toggle callback
- `.focusable(handle: FocusHandle)` — keyboard focusable

Element implementation:
1. `request_layout`: Flex row, align_center, gap=CHECKBOX_GAP. Two children: the checkbox box (a small Div-like area — but since we're an Element, we'll handle this via two layout nodes), and the label TextElement. For the box, request a fixed-size layout node. For the label, create TextElement with appropriate font.

   Practical approach: Use a single flex row container with two child layout nodes:
   - Child 1: Fixed square (e.g., 18x18 for Md) — painted as the checkbox box in paint()
   - Child 2: TextElement for the label

2. `prepaint`: Register hitbox for entire row (clicking anywhere toggles). Register focusable.

3. `paint`:
   - **Unchecked**: Bordered square — 1px border in Border color, transparent fill
   - **Checked**: Filled square in Accent color, white checkmark character "check" painted inside. Use TextElement for checkmark or just paint a small styled rect with Accent bg.
   - **Disabled**: Reduce alpha to 0.5 on all colors (CONTEXT: dimmed 50%)
   - **Hover**: BgElevated on the overall container (CONTEXT: background highlight only)
   - **Focus ring**: If focused via keyboard, show 2px ring around checkbox box using Accent color
   - Label: FgPrimary (normal), FgMuted at 50% alpha (disabled)

For the checkmark, the simplest approach is to render a TextElement with Unicode checkmark character in white/BgPrimary color when checked. Alternatively, just fill the box solid with Accent — both work.

**Toggle** (also part of WIDGET-03):

```rust
const TOGGLE_WIDTH_SM: f32 = 28.0;
const TOGGLE_WIDTH_MD: f32 = 36.0;
const TOGGLE_HEIGHT_SM: f32 = 14.0;
const TOGGLE_HEIGHT_MD: f32 = 18.0;
const TOGGLE_KNOB_INSET: f32 = 2.0;  // gap between knob and track edge

pub struct Toggle {
    checked: bool,
    disabled: bool,
    on_change: Option<Box<dyn Fn(bool) + 'static>>,
    focus_handle: Option<FocusHandle>,
}
```

Builder API:
- `toggle() -> Toggle` — constructor (no label, toggle is just the switch)
- `.checked(bool)` — set on/off state
- `.disabled(bool)` — disable
- `.on_change(handler)` — toggle callback
- `.focusable(handle)` — keyboard focusable

Element implementation:
1. `request_layout`: Fixed size layout (TOGGLE_WIDTH_MD x TOGGLE_HEIGHT_MD). Single layout node for the pill track.
2. `prepaint`: Register hitbox, register focusable.
3. `paint`:
   - **Track (off)**: Pill-shaped rect (border_radius = height/2) with BgSecondary fill
   - **Track (on)**: Pill-shaped rect with Accent fill
   - **Knob**: Small circle (border_radius = knob_size/2) painted at left (off) or right (on) side of track. Knob is white/FgPrimary color. Knob size = track height - 2*TOGGLE_KNOB_INSET.
   - **Disabled**: 50% alpha on all colors
   - **Hover**: Slight brightening of track (BgElevated for off, AccentHover for on)

Toggle state struct:
```rust
pub struct ToggleState {
    layout_id: LayoutId,
    hitbox_id: Option<HitboxId>,
    focus_id: Option<FocusId>,
}
```

For the knob: In paint(), calculate knob bounds based on checked state:
- Off: knob_x = track_bounds.x + TOGGLE_KNOB_INSET
- On: knob_x = track_bounds.x + track_width - knob_size - TOGGLE_KNOB_INSET
Paint a small styled rect with full border_radius for circular appearance.
