Create `ora/src/elements/tab.rs` implementing the Tab widget (WIDGET-05).

Tab renders an individual tab with active/inactive styling and an optional close button.

NOTE: This plan does NOT depend on Plan 01 (WidgetSize). Tab uses its own fixed sizing constants since tabs have specific height requirements (TAB_BAR_HEIGHT=36px from Phase 7). If WidgetSize is available when this runs, feel free to import it, but do NOT fail if it's not — use local constants instead.

Structure:
```rust
use crate::element::{Element, LayoutContext, LayoutId, PaintContext, PrepaintContext};
use crate::elements::text::{TextElement, TextState};
use crate::events::mouse::HitboxId;
use crate::style::*;
use crate::theme::{ColorToken, Theme};

const TAB_HEIGHT: f32 = 36.0;
const TAB_PADDING_H: f32 = 12.0;
const TAB_FONT_SIZE: f32 = 13.0;
const CLOSE_BUTTON_SIZE: f32 = 16.0;

pub struct Tab {
    label: String,
    is_active: bool,
    is_dirty: bool,
    show_close: bool,
    on_click: Option<Box<dyn Fn() + 'static>>,
    on_close: Option<Box<dyn Fn() + 'static>>,
    // Internal text elements
    label_element: Option<TextElement>,
    close_element: Option<TextElement>,
}
```

Builder API:
- `tab(label: impl Into<String>) -> Tab` — constructor
- `.active(bool)` — set active state
- `.dirty(bool)` — show dirty indicator (dot before label)
- `.show_close(bool)` — show close button (default true)
- `.on_click(handler)` — tab click handler
- `.on_close(handler)` — close button handler

Element implementation:
1. `request_layout`: Flex row style with h=TAB_HEIGHT, padding_h. Create label TextElement (prepend dot if dirty). If show_close, create close TextElement ("x"). Request layout for container + children.
2. `prepaint`: Register hitbox for entire tab. If show_close, register separate hitbox for close button area.
3. `paint`:
   - Active tab: BgPrimary background, Accent bottom border (2px), FgPrimary text
   - Inactive tab: BgSecondary background, no bottom border, FgSecondary text
   - Hover: BgElevated background
   - Close button: show "x" in FgMuted, hover highlight with BgElevated circle
   - Dirty indicator: Warning-colored dot before label text

State struct stores layout_id, label text state, close button text state, hitbox IDs for tab and close button.

Write tests:
- `test_tab_creation` — verify default values: is_active=false, is_dirty=false, show_close=true, label matches input
- `test_tab_active_state` — verify builder chain: `tab("Test").active(true).dirty(true)` sets fields correctly
  </action>
  <verify>Run `cargo test -p ora` to confirm compilation and all tests pass including new tab tests.</verify>
  <done>Tab element renders with active/inactive states, dirty indicator, and close button. Unit tests verify creation and active state builder.</done>

TreeItem renders a tree node with expand/collapse chevron and indentation level.

Structure:
```rust
const TREE_ITEM_HEIGHT: f32 = 24.0;  // sm tier
const INDENT_WIDTH: f32 = 16.0;
const CHEVRON_WIDTH: f32 = 16.0;
const ICON_WIDTH: f32 = 16.0;
const TREE_FONT_SIZE: f32 = 12.0;  // sm tier font

pub struct TreeItem {
    label: String,
    depth: usize,
    is_dir: bool,
    is_expanded: bool,
    is_selected: bool,
    icon_color: Option<Color>,  // file-type icon color
    on_click: Option<Box<dyn Fn() + 'static>>,
    on_toggle: Option<Box<dyn Fn() + 'static>>,  // expand/collapse
    // Internal elements
    chevron_element: Option<TextElement>,
    icon_element: Option<TextElement>,
    label_element: Option<TextElement>,
}
```

Builder API:
- `tree_item(label: impl Into<String>) -> TreeItem`
- `.depth(n: usize)` — indentation level
- `.directory(expanded: bool)` — marks as directory with expand state
- `.selected(bool)` — selection highlight
- `.icon_color(color: Color)` — file-type icon color
- `.on_click(handler)` — selection handler
- `.on_toggle(handler)` — expand/collapse handler

Element implementation:
1. `request_layout`: Flex row, h=TREE_ITEM_HEIGHT, align_center. Calculate left padding as `depth * INDENT_WIDTH`. Create children: chevron TextElement (if is_dir: expanded="v" collapsed=">", else empty spacer), icon TextElement (dir: folder icon, file: colored dot), label TextElement.
2. `prepaint`: Register hitbox for entire row. If is_dir, register separate hitbox for chevron area.
3. `paint`:
   - Default: transparent bg
   - Selected: Selection token bg (or Accent with low alpha)
   - Hover: BgElevated (CONTEXT: background highlight)
   - Chevron: FgMuted, use "v" for expanded and ">" for collapsed
   - Icon: Use icon_color if provided, otherwise FgMuted for dirs, FgSecondary for files
   - Label: FgPrimary
   - Indent guides: For each depth level, paint a thin 1px vertical line in Border color. Use indent guide rendering approach: loop through 0..depth, for each level calculate x position and paint a thin rect.
