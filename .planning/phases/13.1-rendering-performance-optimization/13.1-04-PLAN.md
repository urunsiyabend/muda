  <action>
  1. Add FrameDegradation struct (can be defined in event_loop.rs or a small module):
     ```rust
     struct FrameDegradation {
         consecutive_slow: u32,
         degraded: bool,
     }
     impl FrameDegradation {
         fn new() -> Self { Self { consecutive_slow: 0, degraded: false } }
         fn update(&mut self, frame_ms: f64) {
             if frame_ms > 4.0 {
                 self.consecutive_slow += 1;
                 if self.consecutive_slow >= 3 { self.degraded = true; }
             } else {
                 self.consecutive_slow = 0;
                 self.degraded = false;
             }
         }
     }
     ```

  2. Add `frame_degradation: FrameDegradation` field to the event loop handler. Call `frame_degradation.update(total_ms)` after each frame render.

  3. When `frame_degradation.degraded` is true, suppress transition animations:
     - The transition system lives in `ora/src/context.rs`: `AppContext.transition_registry: RefCell<TransitionRegistry>` with method `has_active_transitions()` at line 455.
     - When degraded, skip the transition tick call in the event loop (the code that calls `has_active_transitions()` to decide whether to request_redraw). This means: if degraded and the only reason for redraw is active transitions, skip the redraw request. Elements will render with their current interpolated value (no further easing steps).
     - When degraded recovers (consecutive_slow resets to 0), resume normal transition behavior automatically.

  4. Add `--no-cache` CLI flag that sets both --no-glyph-cache and --no-layout-cache:
     - Parse from args, set both flags.
     - This is the umbrella A/B comparison flag.

  5. Update --show-fps to show both glyph and layout hit rates:
     ```
     "Muda [{total}ms | view {v} layout {l} prepaint {p} paint {pa} gpu {g} | glyph {g_rate}% layout {l_rate}% | {cmds} cmds | {fps}fps]"
     ```
     Read glyph rate from text_system.cache_hit_rate() and layout rate from the event loop's layout_hits/(layout_hits+layout_misses).

  6. If degraded, add "[DEGRADED]" to the --show-fps title bar so it's visible during testing.
