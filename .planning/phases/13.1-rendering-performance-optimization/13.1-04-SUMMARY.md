## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Layout cache gray screen fix**
- **Found during:** Human verification
- **Issue:** Layout cache path skipped request_layout(), so fresh element trees had no LayoutIds — gray screen
- **Fix:** Always run request_layout() (assigns IDs), only skip compute_flexbox() on cached frames
- **Files modified:** ora/src/platform/event_loop.rs
- **Committed in:** `3ad0480`

**2. [Rule 3 - Blocking] Glyph cache not wired to TextElement**
- **Found during:** Human verification (0% glyph hit rate in logs)
- **Issue:** measure_text_cached() existed but TextElement still called measure_text()
- **Fix:** Changed TextElement to use measure_text_cached() + paint_text_cached()
- **Files modified:** ora/src/elements/text.rs
- **Committed in:** `b5e266f`

**3. [Rule 1 - Bug fix] Glyph cache pop() caused 46% miss rate**
- **Found during:** Log analysis after human verification
- **Issue:** pop() removed cache entry on hit; duplicate texts (same line appearing twice) always missed on second occurrence
- **Fix:** Changed to peek() + clone() so entries persist; insert on miss immediately
- **Files modified:** ora/src/rendering/text.rs
- **Committed in:** `b454878`

**Impact on plan:** All fixes were critical for correctness and performance. Without them, the optimization stack was non-functional (gray screen, 0% cache, 54% cache respectively).
