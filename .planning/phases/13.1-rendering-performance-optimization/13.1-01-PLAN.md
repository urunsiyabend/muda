<objective>
Add a global LRU glyph buffer cache to TextSystem so that identical text lines are shaped once and reused across frames and buffers.

Purpose: Glyphon set_text() + shape_until_scroll() is the single most expensive per-frame operation. Caching shaped Buffers keyed on (text_hash, font_size, line_height) eliminates redundant shaping for unchanged lines.

Output: TextSystem with LRU cache, cache-aware measure_text_cached(), buffer return path from GPU render, glyph hit rate in --show-fps, --no-glyph-cache debug flag.
</objective>

<task type="auto">
  <name>Task 1: Glyph buffer LRU cache in TextSystem</name>
  <files>ora/src/rendering/text.rs, ora/src/element/trait_def.rs</files>
  <action>
  1. In text.rs, add `GlyphCacheKey` struct:
     ```rust
     #[derive(Clone, Copy, PartialEq, Eq, Hash)]
     pub struct GlyphCacheKey {
         pub text_hash: u64,
         pub font_size_bits: u32,
         pub line_height_bits: u32,
     }
     ```
     Use `std::hash::{Hash, Hasher}` with `DefaultHasher` to hash text content into u64. Convert f32 to u32 bits via `f32::to_bits()`.

  2. Add to TextSystem struct:
     - `glyph_cache: LruCache<GlyphCacheKey, glyphon::Buffer>` (capacity 2048)
     - `cache_hits: u64`
     - `cache_misses: u64`
     - `cache_enabled: bool` (default true, for --no-glyph-cache)
     Import `use lru::LruCache;` and `use std::num::NonZeroUsize;` (same pattern as texture.rs).

  3. Add `measure_text_cached(&mut self, text: &str, font_size: f32, line_height: f32, max_width: Option<f32>) -> (GlyphCacheKey, Buffer, Size<f32>)`:
     - Compute GlyphCacheKey from text hash + font_size.to_bits() + line_height.to_bits()
     - If cache_enabled and key exists in cache: pop the Buffer out of the cache (LruCache::pop), measure its layout_runs for size, increment cache_hits, return (key, buffer, size)
     - Otherwise: call existing measure_text() logic, increment cache_misses, return (key, buffer, size)
     - IMPORTANT: We pop (remove) from cache because Buffer is moved into PaintCommand::Text. It gets returned after render_frame().

  4. Add `return_buffers_to_cache(&mut self, buffers: Vec<(GlyphCacheKey, glyphon::Buffer)>)`:
     - For each (key, buffer), call `self.glyph_cache.put(key, buffer)` to return it to the LRU cache.
     - Only if cache_enabled.

  5. Add `cache_hit_rate(&self) -> f64`:
     - Return hits / (hits + misses) as f64, or 0.0 if no calls yet.

  6. Add `set_cache_enabled(&mut self, enabled: bool)` and `reset_cache_stats(&mut self)`.

  7. In trait_def.rs, extend `PaintCommand::Text` to carry `Option<GlyphCacheKey>`:
     ```rust
     Text {
         buffer: glyphon::Buffer,
         left: f32,
         top: f32,
         bounds: Rect,
         color: Color,
         cache_key: Option<GlyphCacheKey>,
     }
     ```
     Update `PaintContext::paint_text()` to accept an optional GlyphCacheKey and pass it through. Add a convenience method `paint_text_cached()` that takes a GlyphCacheKey. The existing `paint_text()` should pass `cache_key: None` for backward compatibility.

  Do NOT change any call sites that use measure_text() yet -- they will be migrated incrementally. The existing measure_text() remains as-is.
  </action>
  <verify>
  `cargo check` passes with no errors. The new types and methods compile. Existing code is unaffected (backward compat via cache_key: None).
  </verify>
  <done>
  TextSystem has LruCache<GlyphCacheKey, Buffer> with capacity 2048. measure_text_cached() computes hash key, checks cache, falls back to shaping. PaintCommand::Text carries optional GlyphCacheKey. return_buffers_to_cache() accepts returned buffers. cache_hit_rate() reports stats.
  </done>

<task type="auto">
  <name>Task 2: Buffer return path from render_frame + --show-fps glyph stats + --no-glyph-cache flag</name>
  <files>ora/src/platform/gpu.rs, ora/src/platform/event_loop.rs, ora/src/rendering/text.rs</files>
  <action>
  Buffer return design (one approach, no alternatives):

  glyphon's TextRenderer::prepare() borrows Buffers via TextArea references (`.iter()` over pending_buffers). render() only takes a RenderPass and does not access Buffers at all. clear() drops pending_buffers. Therefore, Buffers remain valid and owned by TextSystem throughout the prepare/render cycle. The return path extracts them AFTER render but BEFORE clear.

  1. In text.rs, extend TextEntry to carry `cache_key: Option<GlyphCacheKey>`:
     ```rust
     struct TextEntry {
         buffer: Buffer,
         left: f32,
         top: f32,
         bounds: TextBounds,
         default_color: GlyphonColor,
         cache_key: Option<GlyphCacheKey>,  // NEW
     }
     ```

  2. Update `add_text_area()` and `add_text_area_for_layer()` signatures to accept `cache_key: Option<GlyphCacheKey>`. Store it in the TextEntry. Update all existing call sites to pass `None`.

  3. Add `drain_buffers_for_cache(&mut self) -> Vec<(GlyphCacheKey, glyphon::Buffer)>`:
     - Drain pending_buffers and pending_layers (all layers) using `.drain(..)`.
     - For each TextEntry with `cache_key: Some(key)`, collect `(key, entry.buffer)` into the result Vec.
     - Entries with `cache_key: None` are dropped (no cache return).
     - This replaces the existing `clear()` call for the frame -- after draining, pending_buffers is empty.
     - Still call `self.atlas.trim()` at the end (same as current `clear()` does).

  4. In gpu.rs, when processing PaintCommand::Text, pass the `cache_key` field through to `text_system.add_text_area()` or `text_system.add_text_area_for_layer()`.

  5. In event_loop.rs, after `render_frame()` returns Ok, replace the existing `text_system.clear()` call with:
     ```rust
     let returned = gpu_state.text_system.drain_buffers_for_cache();
     gpu_state.text_system.return_buffers_to_cache(returned);
     ```

  6. In event_loop.rs, add `--no-glyph-cache` CLI flag:
     - Add a new `static NO_GLYPH_CACHE: AtomicBool` similar to SHOW_FPS.
     - Parse from `std::env::args()` in the init function (same place as --show-fps).
     - After TextSystem creation, if flag is set, call `text_system.set_cache_enabled(false)`.

  7. Extend the --show-fps title bar format to include glyph cache hit rate:
     ```
     "Muda [{total}ms | view {v} layout {l} prepaint {p} paint {pa} gpu {g} | glyph {rate}% | {cmds} cmds | {fps}fps]"
     ```
     Call `gpu_state.text_system.cache_hit_rate()` to get the rate.
  </action>

  </verify>

  Buffers are returned to the LRU cache after each frame's render. --show-fps displays glyph cache hit rate. --no-glyph-cache disables the cache. Scrolling through unchanged lines shows high cache hit rate.
  </done>
