**Part A: Selection dimming on focus loss**

1. In `ora/src/theme/tokens.rs`, add a `SelectionInactive` color token:
```rust
SelectionInactive,
```
Assign it a dimmed version of the Selection color in both dark and light themes. For dark theme: same hue as Selection but with lower alpha (~15% opacity instead of ~30%). Implement by creating a darker/more transparent version of the selection color.

2. In `ora/src/views/text_area.rs`:
- Add `editor_focused: bool` field to `TextAreaView`
- Add `with_focus_state(self, focused: bool) -> Self` method
- In `render_selection_bg_layer`, use `ColorToken::SelectionInactive` when `!self.editor_focused` and `ColorToken::Selection` when focused

3. In `ora/src/platform/event_loop.rs`:
- Add `editor_has_focus: bool` field to `OraApp`, initialized to `true`
- In `WindowEvent::Focused(focused)` handler, set `self.editor_has_focus = focused` and request redraw
- Pass `editor_has_focus` to the adapter (or through render model). Simplest: add `editor_focused: bool` field to `RenderModel` in `ora/src/editor_adapter/types.rs`
- In `EditorRootView::build_layout`, pass `model.editor_focused` to `TextAreaView::with_focus_state()`
- In event_loop RedrawRequested, set `model.editor_focused = self.editor_has_focus` after building the model (similar to how scroll_y_offset_px is set)

**Part B: Gutter click to select line**

4. Add `GutterClickAt { line: usize }` variant to EditorCommand in both:
- `ora/src/editor_adapter/types.rs`
- `core_editor/src/commands/editor_command.rs`

5. In `core_editor/src/commands/dispatcher.rs`, handle GutterClickAt:
```rust
EditorCommand::GutterClickAt { line } => {
    self.handle_gutter_click(ctx, line);
    DispatchResult::Executed
}
```
`handle_gutter_click` selects the entire line: anchor = line start offset, head = next line start (or doc end). Move caret to end of selection.

6. In `wgpu_client/src/adapter.rs`, add GutterClickAt to `to_core_command` conversion.

7. In `ora/src/platform/event_loop.rs`, detect clicks in the gutter region:
- Gutter occupies x from `sidebar_px` to `sidebar_px + gutter_px`
- On mouse click in this region, compute line from y coordinate (same as text area: `scroll_y + floor((y - TAB_BAR_H + scroll_y_offset_px) / LINE_HEIGHT)`)
- Dispatch `EditorCommand::GutterClickAt { line }`

**Part C: Ensure selection extends to full line width**

8. Verify in `ora/src/views/text_area.rs` `render_selection_bg_layer` that when `end_col >= total_chars`, the selection rect uses `grow(1.0)` to fill remaining width. This is already implemented (check the existing code). If it works correctly, no changes needed.

9. Verify caret remains visible and blinking during selection. The caret is rendered in Layer 5 on top of selection (Layer 3). The caret blink system (notify_caret_activity) should continue working. Verify no code hides the caret when selection is active.
