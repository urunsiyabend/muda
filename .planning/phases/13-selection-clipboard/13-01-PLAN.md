1. In `ora/src/editor_adapter/types.rs`, add two new variants to `EditorCommand`:

```rust
/// Click at a document position (from mouse click in text area).
/// line and col are 0-indexed document coordinates.
/// extend_selection: true if Shift was held (extend from anchor).
/// click_count: 1=single, 2=double (word), 3=triple (line).

/// Drag to a document position (from mouse move during drag).
/// line and col are 0-indexed document coordinates.
DragTo { line: usize, col: usize },
```

2. In `core_editor/src/commands/editor_command.rs`, add matching variants:

```rust
/// Mouse click at document position.
ClickAt { line: usize, col: usize, extend_selection: bool, click_count: u32 },
/// Mouse drag to document position.
DragTo { line: usize, col: usize },
```

Mark both as `affects_selection`. ClickAt with click_count > 1 is editing-neutral.

3. In `core_editor/src/commands/dispatcher.rs`, add handler:

```rust
EditorCommand::ClickAt { line, col, extend_selection, click_count } => {
    self.handle_click_at(ctx, line, col, extend_selection, click_count);
    DispatchResult::Executed
}
EditorCommand::DragTo { line, col } => {
    self.handle_drag_to(ctx, line, col);
    DispatchResult::Executed
}
```

Implement `handle_click_at`:
- Clamp `line` to `0..document.len_lines()-1`
- Clamp `col` to `0..document.line_len(line)`
- Compute offset via `document.position_to_offset(TextPosition::new(line, col))`
- If `click_count == 1`:
  - If `extend_selection`: call `ctx.view.move_caret_to(offset, true)`
  - Else: call `ctx.view.move_caret_to(offset, false)` then `ctx.view.clear_selection()`
- If `click_count == 2`: select the word under the cursor (find word boundaries using char class: alphanumeric+underscore vs punctuation vs whitespace, matching VS Code rules). Set anchor to word start, head to word end via `begin_selection` + `move_caret_to(word_end, true)`.
- If `click_count == 3`: select the entire line including trailing newline. Anchor = line start offset, head = next line start (or doc end).
- Emit selection_changed event.

Implement `handle_drag_to`:
- Clamp line/col same as click_at.
- Compute offset.
- Call `ctx.view.move_caret_to(offset, true)` (always extends selection from anchor).
- Emit selection_changed event.

```rust
fn sidebar_width_chars(&self) -> usize {
    if self.app.sidebar.visible { self.app.sidebar.width } else { 0 }
}
fn gutter_width_chars(&self) -> usize {
    let total_lines = self.app.workspace.active_document()
        .map(|d| d.len_lines()).unwrap_or(1);
    let digits = total_lines.to_string().len();
    digits + 2 // digits + space + separator
}
```

3. In `ora/src/platform/event_loop.rs`, in the WindowEvent::MouseInput Pressed handler:
- Compute the text area origin:
  ```rust
  let char_w = crate::rendering::measured_char_width();
  let sidebar_px = adapter.borrow().sidebar_width_chars() as f32 * char_w;
  let gutter_px = adapter.borrow().gutter_width_chars() as f32 * char_w;
  const TAB_BAR_H: f32 = 36.0;
  let text_area_x = sidebar_px + gutter_px + 1.0; // 1px padding
  let text_area_y = TAB_BAR_H;
  ```
- Check if the click is within the text area region (x > text_area_x, y > TAB_BAR_H, y < window_height - STATUS_BAR_H)
- If yes, convert pixel position to (line, col):
  ```rust
  fn pixel_to_doc(
      px: Point, text_area_x: f32, text_area_y: f32,
      char_width: f32, scroll_y: usize, scroll_y_offset_px: f32, scroll_x: usize,
  ) -> (usize, usize) {
      let local_y = px.y - text_area_y + scroll_y_offset_px;
      let local_x = px.x - text_area_x;
      let line_in_viewport = (local_y / LINE_HEIGHT).floor().max(0.0) as usize;
      let line_idx = scroll_y + line_in_viewport;
      let col_raw = ((local_x / char_width) + 0.5).floor().max(0.0) as usize;
      let col_idx = scroll_x + col_raw;
      (line_idx, col_idx)
  }
  ```
  NOTE: The `+ 0.5` provides mid-character snap (past midpoint snaps right).
