<objective>
Fix disappearing text by consolidating all glyphon prepare() calls into a single batch per frame.

Purpose: The current implementation calls ui_text_renderer.prepare() multiple times per frame (sidebar, tabs, status, panel, command palette), which overwrites the glyph vertex buffer each time, causing earlier text to vanish. Glyphon requires a single prepare() call with all TextArea instances.

Output: Modified renderer that collects all TextBlock arrays first, then calls prepare() once, then renders all text in a single pass.
</objective>
